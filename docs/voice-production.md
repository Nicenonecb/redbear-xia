## 模型选择与试音

优先试 MiniMax `speech-2.8-hd`。官方接口提供中文、固定 voice_id、语速调整、停顿标记和发音控制；适合本项目离线逐句制作的工作方式。此推荐是根据功能与任务的匹配作出的选择，并非已经试听本项目后的音质排名。官方依据：[同步语音接口](https://platform.minimax.io/docs/api-reference/speech-t2a-http)、[Speech 2.8 介绍](https://www.minimax.io/news/minimax-speech-28)。

备选 ElevenLabs `eleven_v4`：官方列为高表现力语音模型，支持普通话，可作为角色表演的对照试音。官方依据：[模型说明](https://elevenlabs.io/docs/overview/models)。实际音色、读音与情感表现需用同一组台词听后决定。

红熊音色筛选／声音设计描述（用于支持描述的音色设计界面，不当作朗读文本，不假定 TTS 接口有自然语言 instructions 参数）：

> 中国武侠故事中的中年男性师父，约四十五至五十五岁。声音低沉、温厚、结实，带轻微沙哑但吐字清晰。普通话自然，语速略慢，像当面叮嘱徒弟。威严来自沉稳，关心藏在语气里。欣慰时略带笑意，救场时短促有力，责备时克制。避免播音腔、广告腔和刻意压嗓。干净人声，无音乐、混响和环境音。

建议先用“剑是用来护人的，不是用来逞能的。”“为师还在，倒不了。”“少华，钱能买路，买不回百姓。下一次，拔剑。”各生成 2–3 个版本，覆盖叮嘱、救场与责备。确定音色后固定同一个 voice_id，逐段生成；语速可从 0.9 倍起试听，救场短句接近正常语速。

MiniMax 停顿示例（只用于生成输入，不修改显示字幕）：

```text
出师之后，惩恶扬善，保护百姓。<#0.5#>莫让百姓受伤。
```

`<#秒数#>` 是官方支持的停顿语法。不要把“【欣慰】”“【严厉】”等制作备注直接混入文本，避免被念出来；不同厂商的标签不通用。

## 录制前的文案建议（尚未应用）

- “山下有座山，山上有三个人……”建议改成“此去有座山，山上有三个人，你会碰到他们的。去吧。”减少地理指代的绕口感。
- “胖虎不坏，只是贪”与掳走姑娘的行为存在价值表达冲突；可考虑“胖虎作恶，你阻止得好。可他背后，还有借他作恶的人。山腰那位，你要当心。”这是内容改写，需先确定再同步游戏字幕与配音。
- “无瑕，你放走的人比你打倒的人多”未必符合实际战斗数量；可考虑“无瑕，救得了人，才是真本事。山腰那位出手没轻重，别跟他硬拼，跟他拼脑子。”
- 人名读音逐一试听：少华 shào huá、无瑕 wú xiá、鲍金梁 bào jīn liáng、彰化天 zhāng huà tiān、任新野 rén xīn yě；有误再用发音控制处理。

优化重点是口语节奏、重音和表演，不需要为这几十段对白训练或微调模型。任何改词都同步到字幕，避免音画文案不一致。

## 输出与接入

按既有 `docs/voice-lines.md` 规格交付：MP3 128 kbps 或以上、单声道、44.1 kHz；句首尾各约 0.2 秒空白，目标响度约 -16 LUFS。响度统一需要后期处理和试听，不是单纯调整 API 音量。保留 WAV 母版便于后续处理。

红熊音频放 `public/voice/`，在清单里按 ID 注册，例如两个 ID 复用同一个主题句：

```json
{
  "lines": {
    "redBear_intro_wen_3": "redBear_intro_wen_3.mp3",
    "redBear_intro_yu_3": "redBear_intro_wen_3.mp3"
  }
}
```

这只是示例，完整接入时填写全部 19 个 ID。试听需确认没有漏字、错读、额外语气词，以及跳过／切场景后声音正确停止。其他角色需另补播放接线，不能仅靠登记文件完成。
