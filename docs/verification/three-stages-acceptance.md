## 复验

准备 Chrome 和可供 Node 加载的 `playwright` 包；若包不在项目依赖中，用 `PLAYWRIGHT_MODULE` 指定其绝对目录。先启动无热更新残留的开发服务器，测试过程中不要编辑源码：Vite 的模块时间戳可能使浏览器控制台动态导入与应用持有不同的状态模块。

```sh
npm run typecheck
npm run build
npm run dev -- --host 127.0.0.1
```

在另一个终端运行：

```sh
node tools/verify-three-stages.cjs
BOSS_ONLY=1 node tools/verify-three-stages.cjs
node tools/verify-three-stages-invariants.cjs
```

默认访问 `http://127.0.0.1:5173`，可通过 `TEST_URL` 修改。完整一局低于 14/20 通关或发生卡死时脚本失败；最终 Boss 专项还要求 0.5 有超过半数败在二阶段。机制检查失败或出现浏览器脚本异常时同样失败。
