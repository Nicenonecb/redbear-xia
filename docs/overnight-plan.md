## 我替你先拍板的地方（不满意随时改）

这些在 DESIGN.md 里没写死，为了不卡进度，我先按下面做。所有数值都集中在 `src/characters/` 和 `src/game/` 下的数据文件里，改起来很快。

- **敌人分级**：每个敌人都标了级别（小怪 / 大怪 / 精英 / Boss）。精英这一级先空着，以后直接加。
  - **小怪**：两三刀就倒，前摇短但伤害低；
  - **大怪**：血厚，有霸体（挨打不会被打断），一招重击伤害高，前摇长、有红圈提示，打完后的空当也大。
- **升级三选一**：攻击是伤害 +15%；气血是上限 +20 并回满这 20；身法是移速 +8%，闪避无敌帧 +2。
- **武器**：每档伤害倍率 1.0 / 1.35 / 1.75。商店里有三样东西：
  - "强化当前武器"：每次伤害 +10%，最多 3 次；
  - "购买下一档武器"：买了以后强化次数清零；
  - "金疮药"：回复一半气血。
- **给钱**：放行门槛 120 文，大约一次商店消费。可以选【给 30 文】、【给 120 文】或【倾囊相助】（全部铜钱）。满 300 文算"给得特别多"。台词全部照 DESIGN.md，涨薪的暗示只靠台词本身，不额外点破。
- **红熊救场**：每关一次，血量低于 15% 时触发，把气血回到 50%。救场之后胖虎会再给一次【给钱】的机会。
