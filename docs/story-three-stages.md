# 三关的故事：一座山，三个结拜兄弟

> 2026-10-25 · 用户定下的设定，写成故事底本。台词、过场、出图、配音都以这里为准。
> 配套文件：[开发计划](three-stages-plan.md) · [出图清单](art-batch5-three-stages.md) · [配音清单](voice-lines.md)

## 一句话

红熊门下的徒弟出师下山，从山脚打到山峰，连挑三个结拜兄弟：贪财好色的胖虎、好勇斗狠的鲍金梁、
想复辟前朝的皇子彰化天。打到最后才知道，两个兄弟都是彰化天招兵买马的刀；彰化天败了，带着两个兄弟逃走。

## 已定的设定

| 项 | 定了什么 |
|---|---|
| 主角下山的理由 | **惩恶扬善**。红熊教诲：出师之后要惩恶扬善、保护百姓，不要让百姓受伤 |
| 地点 | 同一座山：**山脚 · 胖虎**，**山腰 · 鲍金梁**，**山峰 · 彰化天** |
| 三人关系 | 结拜兄弟。彰化天是大哥（前朝皇子），鲍金梁二哥，胖虎三弟 |
| 彰化天的计划 | 利用两个兄弟的毛病，鼓动他们招兵买马，**明年拿下杭州**，复辟前朝 |
| 胖虎 | 贪财好色，强抢民女；但"给钱放行"保留，**突出他的可爱** |
| 鲍金梁 | **没有二阶段**，攻击力比胖虎高 |
| 彰化天 | 两个阶段：一阶段**黑发束起**、衣冠整齐；二阶段**白发散开**、上身衣服崩开露出肌肉 |
| 结局 | 彰化天**带着两个兄弟逃走**（给续作留口子） |
| 配音 | 红熊说话要有**配音** |
| 新小怪 | 山腰：老兵矛手、弓手、教头；山峰：前朝死士、旗手（举旗给周围的敌人加速）、护卫统领 |
| 任新野 | 三关都开茶摊：山脚茶摊、山腰驿站、山峰破庙。他总比主角先到，当作一个梗 |
| 护心符 | 第三关商店多卖一样，一次性，能挡一下致命伤 |

## 人物

### 胖虎 · 三弟 · 山脚

- **毛病**：贪财好色，强抢民女。
- **性格**：凶在嘴上，其实贪生怕死、见钱眼开，有点可爱。打不过就认怂，给钱就放行。
- **和兄弟**：最小的弟弟，最听大哥的话；大哥让他"多收钱、多拉人"，他就真去收买路钱、抢人上山。
- **现有美术**：人形、猛虎、变身演出全部出好了，接着用。

### 鲍金梁 · 字旺友 · 二弟 · 山腰

- **来历**：原是官府武官，比武时下手太重打死同僚，走投无路投奔山野当了强盗，和胖虎结拜。
- **毛病**：好勇斗狠，一点小事就能打死人；特别喜欢找人单挑比武。
- **性格**：粗豪、好面子、讲"规矩"，但一输急了就不讲规矩。看不起只会耍嘴皮子的人，敬重真能打的。
- **外形**：健硕武夫，一身肌肉，旧武官的护甲残片（护心镜、护臂）配强盗的粗布衣。用**长矛**。
- **和兄弟**：替三弟出头。在他眼里大哥是"有大志向的人"，自己跟着他是"去当开国功臣"。

### 彰化天 · 大哥 · 山峰

- **来历**：前朝皇子，国破后隐姓埋名，一心复辟。
- **毛病**：阴郁、冷酷，把人当棋子。
- **手段**：看准两个兄弟的毛病，胖虎贪钱就让他收钱，鲍金梁好斗就让他四处挑人比武、收服败者，
  两边一起给他招兵买马、攒粮攒钱，准备明年打杭州。
- **外形**：一阶段黑发长发束起，整齐的旧朝华服（暗纹龙鳞、褪色的皇家纹样），神情阴冷；
  二阶段白发散开，上衣崩开露出精瘦结实的上身。武器是**带金光的长鞭**。
- **结局**：败而不死，带着两个兄弟逃走，留下一句话，给续作埋线。

### 红熊大侠 · 师父

- 开场在练功场教徒弟，说出全作的主题："出师之后，惩恶扬善，保护百姓，莫让百姓受伤。"
- 每关一次濒死救场（现有）；每关过后写信（现有，第二、三关要新写）；通关后出场。
- 说话有**配音**（见[配音清单](voice-lines.md)）。

### 任新野 · 江湖百事通

- 三关都在路边开茶摊：山脚茶摊、山腰驿站、山峰前的破庙（他总能比主角先到，这本身就是一个梗）。
- 每次透露下一个 Boss 的情报，也一点点透出三兄弟的关系和"杭州"。

## 故事怎么一关一关接上

| 关 | 玩家看到的恶 | 打完发现的线索 | 引出下一关 |
|---|---|---|---|
| 一 · 山脚 · 胖虎 | 强抢民女、收买路钱 | 后院囤着大批粮草兵器，账本写着"二哥处已送去三百石" | 胖虎认怂时说漏嘴："我二哥不会放过你的！" |
| 二 · 山腰 · 鲍金梁 | 逼过路人比武，打死不论 | 营里在操练新招来的人，军旗是"彰"字；他败了说出大哥"明年要拿杭州" | 鲍金梁："大哥说了，到了杭州，我就是大将军……" |
| 三 · 山峰 · 彰化天 | 前朝皇子要复辟，拿兄弟当刀 | 他从不在乎两个兄弟；但最后逃走时还是带上了他们 | 逃走留话，续作的口子 |

**关键**：彰化天的阴冷要在前两关**一点点透出来**，不要第三关才第一次出现。

- 第一关：胖虎被打败时，远处山峰上有个人影背手看着（只是一个剪影）。
- 第二关：鲍金梁开打前提一句"大哥说了，见着红熊的徒弟，往死里打"。
- 第三关：彰化天开场第一句就点破前两关："老三贪，老二蠢，都好用。"

### 胖虎的"可爱"和"强抢民女"怎么放在一起

用户要求两样都要：背景里有很多被抢上山的美女，同时保留给钱放行、突出胖虎可爱。做法：

- **民女画成"被关着、等人救"的**：在山寨后院的木笼、绣楼里，神情害怕或冷眼，不是摆着好看的背景板。
- **胖虎的恶是"贪"和"色"，不是残忍**：他抢人是为了"给大哥凑压寨夫人和陪嫁"，说出来又蠢又好笑；
  他从来没真伤过人（反衬鲍金梁一出手就打死人）。
- **打赢**：胖虎认怂，主角放出民女，民女道谢、各自下山。这一段扣上红熊的"保护百姓"。
- **给钱放行**：胖虎收钱放你过去，但民女没救出来。红熊的信里批评一句："钱能买路，买不回百姓。"
  （不是惩罚，只是让玩家知道还有另一条路，下一次可以选拔剑。）

### 彰化天"带着两个兄弟逃走"怎么演

彰化天血量打空后：
1. 他单膝跪地，白发遮面，冷笑一声。
2. 山峰后方冲出两个熟悉的身影：胖虎（已经变回人形，鼻青脸肿）和鲍金梁（缠着绷带），一左一右架起大哥。
3. 三人从悬崖跳下（或者踩着烟雾遁走），彰化天留下一句话。
4. 画面停在空空的山峰，主角收起兵器。红熊的配音响起，进入通关。

## 关卡总览

| 关 | 场景 | Boss | Boss 打法 | 小怪 |
|---|---|---|---|---|

## 开场过场（选完主角之后）

练功场（`bg_training`），红熊和主角。两个主角各一段，最后落在同一句主题上。

**温少华篇**
> 红熊：少华，剑练到这一步，可以下山了。
> 温少华：师父，弟子下山之后，该做些什么？
> 红熊：剑是用来护人的，不是用来逞能的。出师之后，惩恶扬善，保护百姓——莫让百姓受伤。
> 温少华：弟子记下了。
> 红熊：山下有座山，山上有三个人，你会碰到他们的。去吧。

**于无瑕篇**
> 红熊：无瑕，你的镖比为师当年还准。
> 于无瑕：师父过奖。
> 红熊：准，不难；知道该打谁，才难。出师之后，惩恶扬善，保护百姓——莫让百姓受伤。
> 于无瑕：……是。
> 红熊：山下有座山，山上有三个人，你会碰到他们的。去吧。

> 台词是草稿，用户改过再定稿。配音按定稿录。
