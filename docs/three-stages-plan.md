## 已定的设定（摘要）

- 一座山三关：**山脚 · 胖虎** → **山腰 · 鲍金梁（字旺友，长矛）** → **山峰 · 彰化天（金光长鞭）**。三人结拜，彰化天是大哥。
- 主题：红熊教诲"惩恶扬善，保护百姓，莫让百姓受伤"。
- 胖虎保留"给钱放行"、保留可爱；山寨后院有被抢的民女，拔剑打赢要放人。
- 鲍金梁**一个阶段**，伤害比胖虎高；开场擂台单挑，打到一半叫手下一起上。
- 彰化天两个阶段：一阶段黑发束起；二阶段白发散开、上身衣服崩开。最后**带着两个兄弟逃走**。
- 红熊说话**要配音**。
- 新小怪：山腰老兵矛手、弓手、教头；山峰前朝死士、旗手、护卫统领。任新野三关都开茶摊（山脚茶摊、山腰驿站、山峰破庙）。第三关商店卖护心符。

### 第 1 阶段 · 三关的骨架

**目标**：游戏从"一章"变成"一局三关"，每关一张大地图。这一阶段第二、三关先拿竹林地图复制一份占位，Boss 先都用胖虎，只为把流程走通。

**做法**
1. 新建 `src/game/stages.ts`，定义关卡数据，把 `chapter1.ts` 里的东西挪进第一关：
   ```ts
   export type StageId = 'foot' | 'waist' | 'peak';   // 山脚、山腰、山峰
   export interface StageDef {
     id: StageId;
     name: string;              // '山脚 · 竹林'、'山腰 · 兵营'、'山峰 · 行宫'
     map: MapDef;               // 原 CHAPTER1_MAP 的结构
     rooms: RoomDef[];          // 原 CHAPTER1_ROOMS
     steps: ChapterStep[];      // 原 CHAPTER1_STEPS，不含最后的信
     boss: BossId;              // 'pangHu' | 'baoJinliang' | 'zhangHuatian'
     shopLines: ShopLines;
     letters: Record<HeroId, LetterSet>;  // 见第 2 阶段
     ambient: string;           // 环境音的名字（先都用现有的风声）
   }
   export const STAGES: StageDef[] = [FOOT, WAIST, PEAK];
   ```
   `chapter1Map.ts` 改名或拆成 `src/map/stages/foot.ts`，加 `waist.ts`、`peak.ts`（这一阶段内容先复制竹林）。
2. `RunState` 加 `stage: number`（第几关，0 起），`step` 改成"这一关走到第几步"。`save.ts` 的 `VERSION` 改成 2，`loadRun` 按 `STAGES[stage].steps[step]` 校验。
3. `flow.ts` 的 `sceneForStep` / `advanceRun`：这一关的步走完 → 信 → 下一关第 0 步；第三关的信之后 → 通关（第 5 阶段做，先回标题）。
4. `MapScene` 里所有 `CHAPTER1_MAP` / `CHAPTER1_ROOMS` / `BOSS_STEP` / `SHOP_STEP` 改成从 `STAGES[run.stage]` 读。
5. **把 Boss 从 MapScene 里拆出来**（这是这一阶段最大的活，后面两个 Boss 全靠它）：
   - 定一个接口 `BossController`：`spawn()`、`tick()`、`render(delta)`、`checkIntro()`、`hitTargets()`（给主角打的目标）、`dispose()`，再加 `events`（`'intro'`、`'defeated'`、`'yield'` 等）。
   - 胖虎的开场、给钱、变身演出、被打败，从 `MapScene` 挪到 `src/map/bosses/PangHuBoss.ts`。`MapScene` 只调接口，不再出现 `PANGHU`、`tigerSprite` 这些名字。
   - 红色预警、刀光、墨圈这些通用的画法留在 `MapScene` / `fx.ts`，Boss 通过事件请求画。
6. 区域题卡、`win()` 的大字（"竹林 · 过关"）改成用关卡名。
7. 标题画面（只在 dev）：`1` / `2` / `3` 直接到第一 / 二 / 三关的 Boss 跟前，`B` 保留成 `1`。

**验收**
- 新开一局：竹林打到胖虎，过关看信，接着进入"山腰"（地图还是竹林样子，题卡写"山腰"），再打一个胖虎，看信，进"山峰"，再打一个胖虎，看信，回标题。
- 每关中途按 Esc 回标题再【继续】，回到这一关上一个关口；旧存档（VERSION 1）被忽略、不报错。
- `__t.drive(…, __t.autoPlayer(0.75))` 能自动打完三关。
- 第一关的手感、数值、演出和改之前一模一样（变身演出逐帧看一遍）。

### 第 2 阶段 · 开场过场、红熊配音、第一关的故事

**目标**：故事的开头和第一关立住。

**做法**
1. **配音播放**：新建 `src/audio/voice.ts`。
   - 配音文件放 `public/voice/`，登记在 `public/voice/manifest.json`（`"redBear_intro_wen_1": "redBear_intro_wen_1.mp3"`）。文件名、文案见 [voice-lines.md](voice-lines.md)。
   - `voice.play(id)` 返回一个 Promise，播完 resolve；没有这条配音就按字数算一个时长再 resolve（每字约 0.22 秒），字幕照常显示。
   - 音量跟着 `sfx.volume` / `sfx.muted` 走；配音播放时环境音、音效压低一半（ducking）。
   - 用 Phaser 的 `this.load.audio` 在进场景前按需加载，不在 Boot 里全加载。
2. **开场过场** `src/scenes/IntroScene.ts`：选角确认后先进这里，再进第一关。
   - 背景 `bg_training`（已有）；红熊立绘在左（`portrait_redBear`），主角立绘在右（`portrait_wenShaohua` / `portrait_yuWuxia`）；有过场插画（`intro_wen`、`intro_yu`，见出图清单）就用插画。
   - 台词按 [story-three-stages.md](story-three-stages.md)「开场过场」逐句显示（字幕在下方，复用 `SpeechBubble` 或做一个底部字幕条），红熊的句子播配音。
   - J / 空格 下一句，Esc 跳过整段。
   - 存档：开场看完才算第 0 步；读档不再放开场。
3. **胖虎山寨的民女**：
   - 山寨后院加关民女的木笼和绣楼（地图物件 `prop_cage`、`prop_embroidery_tower`；没图先用代码画个笼子），笼子里放几个民女（`map_maiden1_s` … `map_maiden4_s`，用 `MapSprite` 摆上去、站着不动；没图先不放人，只放笼子）。
   - 民女是"背景"，不可交互、不挨打，被打中也没事。
4. **胖虎的台词**按故事文件改：开场加一句、被打败换一句。
5. **拔剑过关后放人**：胖虎认怂 → 镜头移到笼子 → 笼门打开（笼子换成打开的图，或者淡出）→ 民女走出来、道谢一句（字幕即可）→ 再过关。
6. **两版信**：`letters` 改成 `{ sword: string; bribe: string }`。`RunState` 加 `paidOff?: boolean`（这一关是不是给钱过的），信按它选。
7. **任新野**第一关的情报改成提到抢民女和"他还有两个结拜哥哥"。

**验收**
- 新开一局，两个主角各看一遍开场：台词对、红熊有配音（没录的时候按时长自动往下走）、Esc 能跳过。
- 胖虎山寨后院看得到笼子（和民女，如果图到了）。
- 拔剑打赢：放人演出 → 信是"拔剑"版。给钱过关：没有放人 → 信是"给钱"版。
- M 静音时配音也静音；配音时音效变小。

### 第 3 阶段 · 第二关 · 山腰 · 鲍金梁

**目标**：第二关能完整打一遍。

**地图** `src/map/stages/waist.ts`
- 主题：山腰松林、栈道、废兵营。路线：**松林入口（遭遇战）→ 栈道（遭遇战）→ 驿站（任新野）→ 兵营外（遭遇战）→ 演武场（鲍金梁）**。
- 地面：山石路、泥地（`ground_mountain_path`、`ground_drill_yard`）；物件：松树、山石、栈道木桥、兵器架、旧军帐、点将台、"彰"字军旗、拴马桩（见出图清单）。没图时竹子和现有山石顶着。
- 演武场中央有一圈**擂台**（地上一圈木桩 + 绳子，`prop_ring_post`），开打时就是 Boss 战的"能走范围"（复用 `walk.lock`）。

**新小怪** `src/characters/soldiers.ts`（复用 `MapEnemy` 的 AI，只换数值和外形）

| id | 名字 | 级别 | 打法 | 复用 |
|---|---|---|---|---|
| `spearman` | 老兵矛手 | 小怪 | 隔一段距离直线突刺，前摇有寒光；比喽啰够得远 | 喽啰的 AI，招式换成长扇形窄角度 |
| `archer` | 弓手 | 小怪 | 远远放箭，你一靠近就退 | 飞刀手的 AI，飞行道具换箭，飞得更快、伤害更低 |
| `drillmaster` | 教头 | 大怪 | 霸体，抡大刀横扫一圈（地上亮红圈）+ 冲撞 | 头目的 AI |

**鲍金梁** `src/characters/baoJinliang.ts` + `src/map/bosses/BaoBoss.ts`
- **一个阶段，伤害比胖虎高**：每一下的伤害约是胖虎同类招的 1.3 倍；前摇比胖虎短约 25%（但每招仍有地面红色提示）；收招空当比胖虎短。气血和胖虎人形 + 猛虎合计差不多（约 640～700），数值以第 6 阶段为准。
- 招式（长矛，判定都是"细长的扇形"，比胖虎的刀远、窄）：

| id | 名字 | 前摇提示 | 判定 | 怎么躲 |
|---|---|---|---|---|
| `thrust` | 直刺 | 矛尖寒光，地上一道细红线 | 很远很窄（reach ~260, arc ~20） | 往侧面走一步 |
| `thrust3` | 连环三刺 | 第一刺同上，后两刺不再提示，节奏 快-快-慢 | 同上，三次 | 侧走；第三刺前有停顿，可以贴身反打 |
| `sweep` | 横扫千军 | 矛杆往后一拉，脚下亮红色大扇形 | 近、宽（reach ~180, arc ~200） | 后撤或闪避穿过 |
| `vault` | 撑矛飞踢 | 矛往地上一插，你脚下亮红圈 | 落点一圈 | 离开红圈 |
| `charge` | 回马枪 | 他转身背对你走两步（假装撤退），然后猛回身一枪 | 很远的直线 | 看他转身就准备侧闪 |

- **擂台单挑**（他"爱找人单挑"的玩法）：
  1. 走近演武场 → 鲍金梁开场白 → 他把矛往地上一顿，地上立起一圈木桩（擂台），手下全退到圈外，站着起哄。没有【给钱】选项（他不吃这套）。
  2. 擂台里一对一。手下站圈外不动、不挨打。
  3. **血量 50%**：他喊"都给我上"，2 个矛手 + 1 个弓手翻进擂台（一次，不会无限刷）。
  4. 打赢：鲍金梁跪地，说出"大哥明年就要拿下杭州"，手下四散。
- 动作美术：站姿、`ready`（压矛蓄势）、`thrust`（刺出）、`sweep`（横扫）、`vault`（撑矛腾空）、走路帧。没图时用立绘顶着，代码做前冲后仰（现有机制）。
- 第二关的商店：任新野在驿站，台词换成透露鲍金梁的来历（打死同僚）和"他最爱单挑"。
- 第二关的信：按故事文件。

**验收**
- 第二关从入口打到鲍金梁，擂台、50% 叫人、被打败台词都对。
- 用自动打法（0.75）测：鲍金梁比胖虎难，但能过；死了的那几次，回放看每一下都有提示。
- 标题按 `2` 直接到鲍金梁跟前。

### 第 4 阶段 · 第三关 · 山峰 · 彰化天

**地图** `src/map/stages/peak.ts`
- 主题：山顶云海、石阶、前朝旧行宫。路线：**石阶（遭遇战）→ 云海栈桥（遭遇战）→ 破庙（任新野）→ 宫门外（遭遇战）→ 行宫前的平台（彰化天）**。
- 地面：石阶、青石、残雪（`ground_stone_stairs`、`ground_palace`）；物件：古松、云雾（半透明飘动）、残破石狮、断碑、前朝龙旗（褪色）、宫门、香炉。

**新小怪** `src/characters/loyalists.ts`

| id | 名字 | 级别 | 打法 | 复用 |
|---|---|---|---|---|
| `swordsman` | 前朝死士 | 小怪 | 快速两连刺，会闪避（玩家出招前摇时有概率后跳） | 喽啰的 AI + 简单闪避 |
| `bannerman` | 旗手 | 小怪 | 不攻击；举旗时附近敌人攻速 +20%（旗子上一圈金光），优先打他 | 新写一个很简单的 AI |
| `captain` | 护卫统领 | 大怪 | 霸体，双刀旋风斩（地上红圈）+ 冲刺 | 头目的 AI |

**彰化天** `src/characters/zhangHuatian.ts` + `src/map/bosses/ZhangBoss.ts`
- 气血比鲍金梁多一些；两阶段各一半。
- **一阶段**（黑发束起，衣冠整齐）：站得远，用鞭子控场，不太走动。

| id | 名字 | 前摇提示 | 判定 |
|---|---|---|---|
| `lash` | 金鞭直抽 | 鞭身金光一闪，地上一道金红色细线 | 很远很窄的直线（reach ~320） |
