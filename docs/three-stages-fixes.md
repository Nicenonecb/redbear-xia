### 修 1 · Boss 血条名字叠字

**现象**：`docs/verification/peak-awake.png` 里，屏幕上方血条的名字"彰化天 · 前朝皇子 · 白发觉醒"和别的字叠在一起，看不清。

**做法**
1. 先查清是什么叠上去的（可能是：变身时 `human` 和 `awake` 两个都调了 `setBoss`、`UI` 场景重开时旧的文字没删、`BossCard` 的字落在同一处，或者区域题卡）。在提交说明里写清原因。
2. 血条名字改成**两行**：上面一行是名字（"彰化天"），下面一行小字写称号或阶段（"前朝皇子"，二阶段换成"白发觉醒"）。名字太长时缩小字号，不能超出血条宽度。
3. 三个 Boss 都按这个格式：胖虎"胖虎 / 山大王"（变身后"胖虎 / 猛虎"），鲍金梁"鲍金梁 / 字旺友"，彰化天"彰化天 / 前朝皇子"。

**验收**：三个 Boss 战各截一张，彰化天一、二阶段各一张，名字清楚、不叠字。

---

### 修 2 · 地图上的空方框

**现象**：第二、三关缺图的物件被画成空方框，里面写着"彰""遗迹""宫门""军帐"。

**做法**
1. 删掉 `placeDecor` 里画方框和写字的那段。缺图就**不画**，和第一关的规矩一样。
2. 但会挡路的大件（宫门、点将台、破庙这类有 `r` / `solidAt` 的）缺图时，挡路的圆照样记进去，免得人走进"看不见的房子"里。挡路的地方用代码画一个**像样的占位**：一块灰色山石或一堆木料的剪影（可以复用 `mapArt.ts` 里画山石的办法），不要方框，不要写字。
3. "彰"字军旗缺图时，用代码画一根旗杆 + 一面朱红三角旗（不写字）。

**验收**：第二、三关从头走到尾，截 4 张，画面上没有方框和占位文字。

### 修 3 · 缺图时不能拿别的人物顶替

**原则**：缺图时**宁可用一个中性的剪影，也不能用另一个有名有姓的人物的图**。玩家会把"彰化天"认成胖虎、把"鲍金梁"认成山贼头目，故事就乱了。

**做法**
1. 做一个通用的占位：`src/map/placeholderFigure.ts`。按身高、体型（`slim` 瘦高 / `broad` 魁梧 / `small` 矮小）和一个主色，用代码画一个**水墨剪影人**：头、身、手里一根代表兵器的线条（矛、鞭、刀）。头顶写名字，小号、半透明。
2. `MapSprite` 的 `fallback` 允许传这个占位，而不只是一张图。
3. 各人物缺图时的占位：

| 人物 | 占位 | 兵器线条 | 备注 |
|---|---|---|---|
| 鲍金梁 | broad，浓墨 | 一根比人高的矛 | |
| 彰化天 · 一阶段 | slim，浓墨 | 一条金色的线（鞭） | 头顶画一个束起的发髻 |
| 彰化天 · 二阶段 | slim，浓墨 + 一圈淡金描边 | 金色的鞭 | 头顶画散开的白色长发线条 |
| 民女 | small，淡墨 | 无 | 不要用任何主角的图 |
| 山顶观望的人影 | slim，纯黑剪影 | 无 | 只要一个背手站着的轮廓 |
| 新小怪（矛手、弓手、教头、死士、旗手、统领） | 维持现在用山贼图顶着 | — | 小怪长得像山贼问题不大，可以先不改 |

4. 结局"三兄弟逃走"：胖虎用他自己现成的地图图（`map_pangHu_*`，已经有），鲍金梁用他的占位。三个人必须一眼分得清。
5. 说话时右下角的立绘：缺图时**不显示立绘**，只显示台词气泡（现有的 `Portrait` 本来就是"有图才显示"，确认不要传别人的立绘进去）。

**验收**：在一张图都没有的情况下（把 `portrait_baoJinliang`、`map_baoJinliang_*` 等临时从 manifest 拿掉也行）：鲍金梁战、彰化天两个阶段、结局逃走、胖虎山寨放人各截一张。截图里看不到胖虎、头目、于无瑕、温少华的图出现在不该出现的地方。

### 修 4 · 第二、三关要有自己的路线

**现象**：`waist.ts`、`peak.ts` 是 `structuredClone(FOOT_MAP)` 再改名字，路怎么拐、空地在哪儿和第一关完全一样。

**要求**：三关是**同一座山的山脚、山腰、山峰**，走起来要感觉在往上爬，每关的路线形状要不同。

| 关 | 路线形状 | 特色地段 |
|---|---|---|
| 山脚（不改） | 从左下蜿蜒到右上 | 竹林、茶摊、山寨 |
| 山腰 | **之字形盘山路**：从下往上来回折三次 | 中段一截**栈道**：路变窄（宽约 120，平时 200），一侧是悬崖（走不过去的边，画松树和山石），是一场遭遇战的地点；最上面是平坦的兵营和演武场 |
| 山峰 | **一条长长的石阶直上**，中间横过一座**云海栈桥**，最后开阔成行宫前的大平台 | 石阶窄而直，两边是云雾（`prop_cloud`，缺图时用代码画半透明白雾）；行宫平台最宽，彰化天在正中 |

**做法**
1. `waist.ts`、`peak.ts` 不再复制 `FOOT_MAP`，各自写自己的 `path`、`pathWidth`（允许按路段不同宽度，或者加一个"窄路段"列表）、`areas`、`renXinye`、`respawn`、`decor`、`boss`。
2. 地图大小可以不同（山峰可以更窄更高）。
3. 空地顺序照旧：三场遭遇战 + 一个茶摊 + Boss，`steps` 不变。
4. 鲍金梁的擂台半径 470，演武场空地半径至少 560；彰化天的平台空地半径至少 600（鞭子打得远）。

**验收**：三关各截一张**整张地图的缩略图**（把镜头缩小或者另外画一张俯视小图都行），三张形状明显不同；各从头走到尾一次，不会卡在边上。

### 修 5 · 补两条故事线索

1. **胖虎后院的囤粮和账本**（第一关，拔剑打赢后放人时一起出现）：
   - 山寨后院摆几袋粮、几捆兵器（地图物件 `prop_grain_sacks`、`prop_weapon_bundle`；缺图时用代码画的麻袋和木箱）。
   - 放完人，主角走到粮堆旁自动弹一句（字幕）："账本上写着：二哥处已送去三百石……"
   - 给钱过关的路线不出现这一段。
2. **山腰兵营在练兵**（第二关，走进"兵营外"空地时）：
   - 空地一角摆一排木人桩，四五个新兵（用矛手占位）站成一排对着木人桩做刺击（不攻击玩家，循环播 `ready` / `strike` 两个姿势就行）。
   - 走近时弹一句（新兵之间的对话，字幕）："听说明年要去打杭州？" / "嘘——大哥的事少打听！"
   - 遭遇战开打时新兵散开（淡出）。

**验收**：两段各截一张；第一关走"给钱"路线确认没有账本这段。

### 修 7 · 重测难度

1. **自动打法这一轮不许改**（第 5 条规矩）。它是这次边调边写的，再一边改打法一边调数值，测出来的数字就没意义了。
2. 目标（和原计划一致）：
   - 0.75：完整一局通关 60%～75%。
   - 0.5：至少 80% 能打到鲍金梁；**彰化天二阶段要成为 0.5 最常见的死因**（死在二阶段的局数 ≥ 通关局数）。现在 0.5 通关 55%，太简单，要调难。
3. 只能调这些：鲍金梁、彰化天、二三关小怪的数值（气血、伤害、前摇、收招、冷却）。不改第一关，不改主角。
4. 报告里除了通关率，每关再写：平均进 Boss 时的等级和气血、Boss 战平均用时、主角平均挨了几下、红熊救场触发率。
5. 最后写一段"真人试玩要注意的地方"：哪一招最容易挨、哪里可能太难或太简单。**最终难度以用户本人试玩为准**，自动打法的数字只是参考。
