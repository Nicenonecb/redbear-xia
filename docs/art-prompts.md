# 美术出图清单 · 第一章

> 给 Codex / gpt-image / 即梦 等图像模型用。现在游戏里所有画面都是代码画的剪影，**一张图都不出也能玩**。
> 出了哪张，就按下面的步骤放进去，对应的地方会自动替换成图片，没出的继续用剪影。

## 怎么放进游戏

1. 把图片放进 `public/art/`，文件名随意，比如 `wen.png`。
2. 打开 `public/art/manifest.json`，在 `images` 里登记"槽位名: 文件名"：

```json
{
  "images": {
    "portrait_wenShaohua": "wen.png",
    "title": "title.jpg"
  }
}
```

3. 刷新页面就生效。槽位名写错的会被忽略，不会报错。

## 统一画风（每条提示词前面都加上这段）

> 中国水墨画风格，宣纸质感底色（#efe7d6），人物以浓墨剪影为主（#1a1714），只在少数地方点一抹朱红（#b3261e）。笔触有飞白和晕染，留白多，干净，不要其他颜色，不要文字和印章，不要写实照片感。

English version:

> Chinese ink-wash painting style, rice-paper background (#efe7d6), figures mostly in deep black ink silhouette (#1a1714), with only small accents of vermilion red (#b3261e). Visible dry-brush and ink-bleed texture, lots of negative space, clean. No other colors, no text, no seals, not photorealistic.

立绘请用**透明背景 PNG**，人物全身或大半身、站姿，脚底留一点边。几张立绘的光线、笔触尽量一致，可以先出一张，再用它当参考图出其余的。

### `title` 标题画面

> 远山连绵，近处一片竹林在两侧框住画面，竹叶随风飘落。右侧一座孤崖，崖顶站着一个高大的背影，披着朱红斗篷、兜帽上有一对圆圆的熊耳，背后斜插一把长剑，正望着远方的群山。画面中上部大面积留白（要放"红熊大侠"四个字）。

### `portrait_wenShaohua` 温少华 · 江南 · 剑

> 年轻的江湖剑客，翩翩公子，英俊、气度从容。身形修长，长发束冠，宽袖长袍，衣袖和发带被风吹起。一手负在身后，一手持长剑斜垂身侧，剑穗是朱红色，发带是朱红色，腰间挂一枚朱红玉佩。神情自信、温和，站姿挺拔。

注意：这个角色有真人原型，要画得**帅气、体面**，不要滑稽、不要夸张。

### `portrait_yuWuxia` 于无瑕 · 西南 · 扇与暗器

> 年轻的女侠，五官清冷、眼神沉静，不戴斗笠。长发半披，用一根发簪束住。窄袖劲装，身形挺拔，动作干净利落。一手持一把半开的折扇，扇骨边缘一抹朱红；腰间别着几支飞镖，镖尾系朱红穗子。

### `portrait_pangHu` 胖虎 · 山大王（人形）

> 山寨大王，膀大腰圆、圆滚滚的大肚子，满脸刀疤但表情憨厚好笑，一手叉腰，一手把一柄宽背大刀扛在肩上，身披一整张虎皮，虎头搭在他头顶当帽子。搞笑、接地气的感觉，像是要开口念"此山是我开"。刀疤可以用一点朱红。

这个角色是自己人的外号，可以搞笑，但要讨喜，不要丑化。

### `portrait_pangHuTiger` 胖虎 · 猛虎形态

> 一头比普通老虎更壮实的猛虎，水墨画法，横向侧身，压低前身作势要扑，尾巴高高翘起，淡墨画出虎纹，眼睛是一点朱红。

### `portrait_redBear` 红熊大侠

> 一位高大的大侠，看不清面容。披着一件长到脚边的朱红斗篷，兜帽上有一对圆圆的熊耳，背后斜插一把长剑，剑穗随风飘动。站姿沉稳，像一位暗中守护徒弟的师父。这是整张图里唯一大面积用朱红的人物，红色是他的标志。

### `portrait_renXinye` 任新野 · 江湖百事通（茶摊老板）

> 茶摊老板，头戴软脚幞头，穿长衫，笑眯眯地拱手作揖，眉眼弯弯，和善、机灵、让人一看就想跟他聊两句。身旁可以带一张小柜台，上面摆着算盘和茶碗，檐下挂一盏写着"茶"字的朱红灯笼（灯笼上的字可以不画）。

注意：这个角色有真人原型，大家都很喜欢他，要画得**亲切讨喜**。
