# 改造计划：从横版剪影改成"斜俯视大地图"

> 2026-10-17 · 用户试玩第一章后的反馈：不要火柴人横版，要在一张地图上走动（像传奇那种斜俯视）；画质优先，不压缩图。
> 已定：**斜俯视 45° · 键盘 WASD + 招式键 · 每个朝向一张精图 + 代码做动作 · 一张连通的竹林大地图**。
> 做法照旧：分阶段做，每阶段都能玩、都单独提交到 `dev`；本文件里随时更新进度。

## 保留什么、改什么

**原样保留**（和视角无关）：招式表引擎（帧数、取消窗口、蓄力、输入缓冲）、伤害 / 顿帧 / 震屏 / 伤害数字 / 溅墨、升级三选一、铜钱、任新野的茶摊和买卖、胖虎的【拔剑 / 给钱】和全部台词、红熊救场、红熊的信和结尾、存档、音效、选角、标题；已经出好的立绘、图标、印章、信纸、横幅特写、卷轴、Boss 名牌、登场卡。

**要改的**：

| 现在 | 改成 |
|---|---|
| 1280×720 渲染再拉伸，大屏发糊 | 1920×1080 渲染，界面单独一层，地图跟着人走 |
| 左右走 + 跳 | WASD 八个方向走；**俯视角没有跳**，空格改成闪避 |
| 判定框是"身前一个方框" | 判定改成地面上的"扇形 / 圆"，朝哪个方向出招就打哪边 |
| 一屏一屏的战斗房 | 一张连通的竹林大地图：入山 → 深处 → 茶摊 → 山寨前 → 胖虎山寨 |
| 代码画的火柴人剪影 | Codex 画的人物精图（每个朝向一张），走路起伏、出招前冲、受击后仰由代码做 |
| 横版背景画 | 地面贴图 + 竹丛、山石、寨墙、聚义厅等地图物件；原来那几张横版背景改用在"进入新区域"时一闪而过的区域题卡 |

**操作**：WASD / 方向键 走（八个方向）· J 普攻 · K 按住蓄力 · L / 空格 / Shift 闪避（朝移动方向冲）· I 飞镖（于无瑕）· 走到任新野跟前按 J 说话。
